# GMonster

## Requirements

- Python 3.9

## Setup

1. Clone repository

```bash
git clone https://github.com/yourusername/Gmonster.git
cd Gmonster
```

2. Create virtual environment (optional)

```bash
python -m venv env
```

3. Activate environment (if you created virutal enviroment)

```bash
env\Scripts\activate
```

4. Install requirements

```bash
pip install -r requirements.txt
```

5. Run application

```bash
python var.py
```
